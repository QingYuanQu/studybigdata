### Linux基础命令

#### 目录符号

```
.  : 当前目录
.. : 父级目录
~  : 用户目录
```

#### ls

```bash
list : 列举当前目录或指定目录内的文件
ls -l 	# 文件详细信息
ls -a 	# 可以查看到以.开头的隐藏文件
ls /usr # 查看指定目录内的文件 
ll      # ls -l的简写
```

#### cd

```
change directory : 变更目录
```

#### pwd

```shell
print name of current/working directory : 打印工作目录
```

#### mkdir

```
make directory：创建文件夹
```

#### rmdir

```python
remove directory: 删除文件夹
```

#### cp

```
copy : 复制

cp a.txt b.txt
cp a.txt dir1/
cp -r dir1 dir2/
```

#### mv

```
move : 移动文件
```

#### touch

```shell
touch filename # 创建文件
```

#### echo

```shell
echo "hello world" # 标准输出
```

#### 输出重定向

```bash
> : 没有则创建，有则覆盖
>> : 没有则创建，有则追加

echo 'hello world ' > filename.txt (覆盖)
echo 'hello world ' >> filename.txt （追加）
```

## 查看文本文件

##### cat

```
查看文件全部内容
```

##### head

```
head -n 5 文件名
查看文件前5行
```

##### tail

```
tail -n 3 文件名 
查看文件后三行
```

##### more

```
分页查看文件内容
回车：下一行
空格：翻页
```

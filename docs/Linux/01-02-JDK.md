# RPM包安装

rpm命令是RPM软件包的管理工具。

RPM有多种基本的模式：它们是安装、查询、验证、删除等。

- 安装模式：rpm –i

- 查询模式：rpm -q

- 验证模式：rpm –V或 -verify

- 删除模式：rpm –e

- --nodeps 如果该RPM包的安装依赖其它包，即使其它包没装，也强迫安装。

### 配置环境变量

```shell
[root@node1 ~]# vim /etc/profile
export JAVA_HOME=/usr/java/default
```

### 让环境变量生效

```shell
[root@node1 ~]# source /etc/profile
```

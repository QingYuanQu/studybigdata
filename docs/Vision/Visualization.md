你这个判断是对的。AI 时代，数据可视化课程不应该再以“记住 `matplotlib/seaborn/plotly` 函数”为核心，因为函数调用会被自然语言和代码生成替代。课程真正该教的是：**如何把数据与任务形式化，如何选择/设计视觉编码，如何用数学解释为什么有效，如何评估和审计 AI 生成的图**。

可以这样重构。

## 一、课程目标从“会画图”转为“会可视化推理”

学生学完应能：

1. 把数据和任务形式化：变量类型、尺度、关系、查询、决策。
2. 选择视觉编码：位置、长度、角度、面积、颜色、形状、纹理、动画。
3. 用数学解释：投影、距离、估计、优化、信息损失、不确定性。
4. 用 AI 实现：让 AI 写代码，但自己写“可视化规格说明书”。
5. 评估与审计：识别误导、过绘制、颜色错误、统计陷阱。

一句话：**AI 负责实现，学生负责规格、推理、验证和解释。**

## 二、理论骨架：三层结构

### 1. 数据与数学层
讲数据到视觉的映射：

\[
f: \mathcal{D} \rightarrow \mathcal{V}
\]

其中 \(\mathcal{D}\) 是数据空间，\(\mathcal{V}\) 是视觉空间。数学问题包括：

- 标度变换：线性、对数、幂、分位数。
- 距离与相似度：欧氏距离、余弦、马氏距离、KL 散度。
- 统计估计：均值、分位数、密度、回归、不确定性。
- 优化：降维、布局、轴排序、颜色映射。
- 图论与几何：邻接、拉普拉斯、Voronoi、Delaunay、投影。

### 2. 视觉编码层
经典理论必须讲：

- Bertin 视觉变量：位置、大小、颜色、方向、形状、纹理。
- Mackinlay 表达力与有效性：编码是否表达数据关系，是否容易被感知。
- Cleveland & McGill：位置 > 长度 > 角度 > 面积 > 颜色。
- 格式塔：接近、相似、连续、闭合、共同区域。
- 前注意加工：颜色、方向、大小能在 200ms 内被捕捉。
- Tufte：数据墨水比、小倍数、图表垃圾。
- Munzner 嵌套模型：数据、任务、编码、算法、交互。

### 3. 认知与评估层
- 任务类型：定位、比较、排序、聚类、分布、相关性、异常。
- 认知负荷、变化盲、确认偏误。
- 不确定性可视化：误差条、分布、集合、概率。
- 伦理与误导：截断轴、双轴、面积夸大、颜色操纵。
- 用户实验：反应时、准确率、统计检验、效应量。

## 三、具体可讲的数学专题

不要单独开“可视化数学”，而是每节课插入 15 分钟数学微课。

| 可视化问题 | 数学 |
|---|---|
| 高维散点图 | PCA、SVD、MDS、t-SNE、UMAP |
| 直方图 bin 宽 | 偏差-方差、MISE，最优 \(h \sim n^{-1/3}\) |
| 密度图 | 核密度估计 \(\hat f(x)=\frac{1}{nh}\sum K(\frac{x-X_i}{h})\) |
| 箱线图 | 分位数、IQR、鲁棒统计 |
| 平行坐标 | 轴排列优化、相关性、聚类 |
| 热力图 | 颜色空间、CIELAB、感知均匀、\(\Delta E\) |
| 网络布局 | 力导向能量、谱布局、拉普拉斯矩阵 |
| 树图 | 矩形分割、Voronoi、Delaunay |
| 地图 | 投影、面积变形、Tissot 指示椭圆 |
| 交互 | 集合运算、信息论、互信息 \(I(X;Y)\) |
| 降维 | 应力函数、KL 散度、邻域概率 |
| 动画 | 插值、缓动、贝塞尔、时间映射 |

例如讲散点图，不要讲 `plt.scatter`，而讲：

- 数据是否高维？需要什么投影？
- 位置通道为什么最准确？
- 过绘制如何用透明度、密度、抖动解决？
- 相关性与回归如何叠加？
- 异常值如何影响感知？

讲颜色，不要讲 `cmap='jet'`，而讲：

- 颜色空间：RGB、HSV、CIELAB。
- 感知均匀：相同距离应产生相同感知差异。
- 亮度单调：顺序数据必须亮度单调。
- 色盲：避免红绿组合。
- 发散数据：双端色图，中点中性。
- 缺失值：灰色，不参与色图。

## 四、教学方法：从问题到数学，而不是从定义到问题

每个图型都用“五问”：

1. 数据是什么类型？名义、有序、区间、比率？
2. 任务是什么？比较、分布、相关、聚类、异常？
3. 视觉通道是什么？位置、长度、颜色、面积？
4. 数学映射是什么？标度、投影、估计、损失？
5. 误差和假设是什么？过绘制、偏差、不确定性、误导？

用对比实验代替背诵：

- Anscombe 四重奏：相同统计量，不同图形。
- Datasaurus：相同均值方差，不同形状。
- Simpson 悖论：聚合与分组结论相反。
- 同一数据用饼图、柱状图、点图，让学生测反应时和准确率，做统计检验。
